# 动手做一台真正的望远镜

和孩子一起，从一块镜子做到一台会自己找星星的望远镜。

**要做的是**：150 mm 口径、焦距 1200 mm（f/8）的牛顿反射望远镜，放在多布森式木头底座上。

- **能看到什么**：土星光环和卡西尼环缝、木星条纹和大红斑、火星极冠、月面上几公里大小的环形山，还有梅西耶星表里的大部分星团、星云和星系
- **为什么选它**：f/8 是公认最适合第一次自己做的规格。光轴校准宽容，副镜小，不需要彗差改正镜，看行星的反差也好。镜筒约 1.25 m、7 kg，大人搬得动，以后装电机也轻松
- **哪些是买的，哪些是自己做的**：主镜和副镜买成品（自己磨镜要几十个小时，见文末）。镜筒、主镜座、底座、电机和电路都自己做
- **不需要木工工具**：所有木板由软件算好尺寸、生成图纸，交给淘宝上的 CNC 切割店加工

> ⚠️ **最重要的一条安全规则**：凹面主镜会把阳光聚成一个点，几秒钟就能点燃纸张、烫伤皮肤。主镜不用时一定盖好或面朝下放，**绝对不要拿它对着太阳**。做好的望远镜也永远不要对准太阳。

## 第 0 步：先让软件把尺寸算出来

```bash
python3 -m telescope build --out 图纸
```

软件会算出：

- **镜筒**：长度、调焦座开孔位置、副镜大小和偏移量
- **焦点位置**：调焦座收到底时焦点在哪，保证目镜和树莓派相机都能对上焦
- **重心和底座**：镜筒重心在哪、底座每块板的尺寸、目镜离地多高
- **电机参数**：以后装电机时每圈要走多少步
- **切割图纸**：在 `图纸/` 文件夹里生成 `telescope_150mm.dxf`（发给切割店）和 `.svg`（用浏览器打开预览）

**零件到手以后，一定要量实物、用实测值重算一遍，然后再开孔、锯管子**：

```bash
python3 -m telescope build --focal 1212 --thickness 24 --tube-od 200 --tube-wall 3.9 \
    --focuser-height 52 --focuser-travel 32 --out 图纸
```

| 参数 | 怎么量 |
|---|---|
| `--focal` | 主镜实际焦距。商家标 1200 mm 的镜子，实际可能差 ±1%（十几毫米），一定要实测，方法见第 1 阶段第 2 步 |
| `--thickness` | 主镜边缘厚度，用卡尺或直尺量 |
| `--tube-od` / `--tube-wall` | 管子外径和壁厚 |
| `--focuser-height` | 调焦座装在管子上、抽筒收到底时，从管子外表面到抽筒顶端的高度 |
| `--focuser-travel` | 抽筒从收到底拉到最长，一共能伸出多少 |
| `--camera` | 按哪台相机设计焦点：`hq`（树莓派 HQ）或 `80d`（佳能 80D）。**要用单反拍照，一定要在开孔、锯管子之前就选 `80d`**，见第 4 阶段 |

### 第 4 阶段：相机（用家里的佳能 80D）

### 设计时就要按 80D 算

单反的卡口离传感器很远（佳能 EF 卡口 44 mm，加上 T 环一共 55 mm），比树莓派相机远 4 倍。很多商品牛反的焦点不够往外，单反根本对不上焦。我们自己做，可以一开始就按 80D 设计：

```bash
python3 -m telescope build --aperture 200 --focal 1200 --thickness 33 --tube-od 250 \
    --tube-wall 4.9 --camera 80d --out 图纸
```

200 mm f/6 按 80D 设计后：

| 项目 | 结果 |
|---|---|
| 焦点 | 调焦座收到底时在抽筒外约 68 mm，80D 一插上就能对焦 |
| 目镜 | 先插一节 **50 mm 延长筒** 再插目镜 |
| 副镜 | 短轴 50 mm，挡光 25%。80D 画面四角亮度约 84%，拍一组平场就能修正 |
| 平衡 | 80D 比目镜重约 0.5 kg，换上以后把镜筒在托架里往后挪约 35 mm |

### 80D 能拍什么

| 目标 | 效果 | 怎么拍 |
|---|---|---|
| 🌕 月亮 | **最好拍**。整个月亮占画面一半，2400 万像素能看清很多环形山 | 1/200–1/1000 秒，ISO 100–400，连拍几十张叠加 |
| 🌌 亮的星云星团（M42、M45、M13、M31） | 能拍出颜色 | 单张 10–20 秒，ISO 1600–3200，拍几十到几百张叠加 |
| 🪐 行星 | 一般。行星在 1200 mm 焦距下只有几十个像素 | 加 2× 巴洛镜录视频。以后换树莓派 HQ 或专门的行星相机效果更好 |
| ☀️ 太阳 | **必须**在镜筒前面装正规的太阳滤膜 | 没有滤膜时永远不要拍 |

### 两点限制

- **彗差**：f/6 牛反的画面四角，星点会被拉成小彗星的样子（约 12 角秒）。拍月亮看不出来；拍星云星团想要四角也圆，就加一个彗差改正镜
- **视场旋转**：多布森是上下、左右两个轴的地平式底座，电机跟踪时画面会慢慢转。单张曝光控制在 15–20 秒以内，叠加软件会把旋转转回来。智能望远镜也是这么做的

### 软件控制

80D 用 USB 线接树莓派，可以用 `gphoto2` 遥控拍摄：自动连拍，把照片传到平板上一起看。以后还能拍一张照片，让软件认出望远镜正指向哪里（星图解算），自动寻星就不需要手动校准了。这部分是接下来要写的软件。

### 现在就能用 80D 做的事

望远镜还没做好，80D 加三脚架和现有镜头已经能拍星空：

- **银河、星轨**：用最广的镜头，光圈开到最大，ISO 3200，曝光约 15 秒
- **月亮**：用最长的长焦镜头
- **流星雨**：对着辐射点附近连续拍，`python3 -m telescope events` 会告诉你哪天有

## 以后：自己磨一块主镜

真正“从零开始”的做法是自己磨主镜：两块玻璃圆盘对着磨，配上金刚砂，从粗磨、细磨一直到抛光，再用傅科检验仪检测抛物面。150 mm f/8 正好是公认最适合第一次磨的规格。

做完这台望远镜以后，可以买一套“150 磨镜套件”，把磨好的镜子换上去。一般要花 30–60 个小时，适合当一个寒假或暑假的项目。
