# 动手做一台真正的望远镜

和孩子一起，从一块镜子做到一台会自己找星星的望远镜。

**要做的是**：150 mm 口径、焦距 1200 mm（f/8）的牛顿反射望远镜，放在多布森式木头底座上。

- **能看到什么**：土星光环和卡西尼环缝、木星条纹和大红斑、火星极冠、月面上几公里大小的环形山，还有梅西耶星表里的大部分星团、星云和星系
- **为什么选它**：f/8 是公认最适合第一次自己做的规格。光轴校准宽容，副镜小，不需要彗差改正镜，看行星的反差也好。镜筒约 1.25 m、7 kg，大人搬得动，以后装电机也轻松
- **哪些是买的，哪些是自己做的**：主镜和副镜买成品（自己磨镜要几十个小时，见文末）。镜筒、主镜座、底座、电机和电路都自己做
- **不需要木工工具**：所有木板由软件算好尺寸、生成图纸，交给淘宝上的 CNC 切割店加工

> ⚠️ **最重要的一条安全规则**：凹面主镜会把阳光聚成一个点，几秒钟就能点燃纸张、烫伤皮肤。主镜不用时一定盖好或面朝下放，**绝对不要拿它对着太阳**。做好的望远镜也永远不要对准太阳。

## 第 0 步：先让软件把尺寸算出来

```bash
python3 -m telescope build --out 图纸
```

软件会算出：

- **镜筒**：长度、调焦座开孔位置、副镜大小和偏移量
- **焦点位置**：调焦座收到底时焦点在哪，保证目镜和树莓派相机都能对上焦
- **重心和底座**：镜筒重心在哪、底座每块板的尺寸、目镜离地多高
- **电机参数**：以后装电机时每圈要走多少步
- **切割图纸**：在 `图纸/` 文件夹里生成 `telescope_150mm.dxf`（发给切割店）和 `.svg`（用浏览器打开预览）

**零件到手以后，一定要量实物、用实测值重算一遍，然后再开孔、锯管子**：

```bash
python3 -m telescope build --focal 1212 --thickness 24 --tube-od 200 --tube-wall 3.9 \
    --focuser-height 52 --focuser-travel 32 --out 图纸
```

| 参数 | 怎么量 |
|---|---|
| `--focal` | 主镜实际焦距。商家标 1200 mm 的镜子，实际可能差 ±1%（十几毫米），一定要实测，方法见第 1 阶段第 2 步 |
| `--thickness` | 主镜边缘厚度，用卡尺或直尺量 |
| `--tube-od` / `--tube-wall` | 管子外径和壁厚 |
| `--focuser-height` | 调焦座装在管子上、抽筒收到底时，从管子外表面到抽筒顶端的高度 |
| `--focuser-travel` | 抽筒从收到底拉到最长，一共能伸出多少 |

## 第 1 阶段：光学件和镜筒

### 1. 认识你的镜子

主镜是一块中间微微凹下去的玻璃，表面镀了一层很薄的铝。**不要用手指碰镜面**，指纹里的油会腐蚀镀膜。拿的时候捏边缘，用完盖好。

主镜中心一般有一个小圆圈标记，校准光轴要用。如果没有，用一个**纸质加固圈贴纸**（打孔纸用的那种）贴在正中心。那里正好被副镜的影子挡住，不影响成像。

### 2. 量出主镜的真实焦距（孩子最喜欢的一步）

在一个有月亮的晚上，把主镜对着月亮，拿一张白卡片在镜子前面慢慢前后移动，卡片上会出现一个小小的、清晰的月亮。月亮最清楚的时候，**卡片到镜面中心的距离就是焦距**。量三次取平均。

> ⚠️ 只能用月亮！千万不能对着太阳做这个实验，卡片会着火。

用量到的焦距重新运行 `build`，记下新的镜筒长度和调焦座位置。

### 3. 做主镜座（CNC 切好的两块圆板）

1. 在主镜托板的三个大孔里敲进 M6 预埋螺母（从背面敲）
2. 三颗 M6×80 螺丝从后板的背面穿过来，每颗套一个弹簧，拧进托板的预埋螺母。三颗螺丝拧得一样深，两块板之间留约 14 mm
3. 后板背面每颗螺丝露出的部分拧上蝶形螺母，以后就靠它校准光轴
4. 在托板三个蓝色定位点上各贴一片软木垫
5. **先不要放镜子**，第 6 步再放

### 4. 镜筒

1. 内壁贴黑色植绒纸（孩子可以帮忙，从一头慢慢往里推着贴）
2. 用记号笔沿管子画一条直线当“基准线”，所有位置都从**尾端**量起
3. 先把主镜座塞进尾端，后板背面和管口齐平，从管壁侧面拧 4–6 颗木螺丝固定
4. 在基准线上量出软件给的**调焦座开孔中心**，用开孔器开孔（大人来做），装上调焦座
5. 在调焦座开孔中心那一圈装副镜支架。四个爪要在同一个截面上：用一根软尺或纸条绕管子一圈画出截面线
6. 装上副镜，按软件说的偏移量，把副镜往主镜方向、背离调焦座方向各挪一点（f/8 只有约 1 mm）
7. 装红点寻星镜，位置在调焦座旁边，看起来顺手就行

### 5. 先别锯管子：白天试对焦

镜筒买了 1.4 m，比需要的长。先装好主镜：

1. 把主镜放在托板的软木垫上，三个镜夹轻轻卡住镜子边缘。**镜夹不能压紧**，镜子能轻微晃动但掉不出来就对了。压紧会让镜子变形，星星看起来像三角形
2. 白天找一个 1 km 以外的目标（远处的楼顶、电视塔，**避开太阳方向**），插上 25 mm 目镜对焦
3. 记下抽筒伸出了多少，和软件的预测比一比。差得多就重新量焦距
4. 确认没问题后，按软件给的长度，从**镜筒口那一头**锯掉多余的部分

### 6. 校准光轴

| 步骤 | 调哪里 | 目标 |
|---|---|---|
| 1 | 副镜支架中心螺丝，转动副镜 | 从调焦座看进去，副镜是正圆、在正中间 |
| 2 | 副镜座的三颗小螺丝 | 主镜完整地出现在副镜里，并且居中 |
| 3 | 主镜座背后的三个蝶形螺母 | 插上柴郡校准目镜，主镜中心的圆圈套住校准目镜的十字 |
| 4 | 主镜蝶形螺母（晚上） | 高倍对准一颗亮星，稍微失焦，光环是同心圆 |

搬动以后一般只需要做第 3 步，两分钟就好。

### 7. 第一次看星（First Light）

把镜筒架在两把椅子之间，先看月亮（记得装月亮滤镜），再用 `python3 -m telescope tonight` 找今晚的行星。

## 第 2 阶段：多布森底座

### 1. 下单切割

把 `图纸/telescope_150mm.dxf` 发给 CNC 切割店，告诉店家：

- 材料：18 mm 桦木多层板，单位毫米
- `CUT` 图层是切割线，`DRILL` 图层是 3 mm 定位孔（只打孔），`LABEL` 图层是文字，不加工
- 侧轴承圆盘、托架板、摇臂箱侧板上的半圆要切得光滑，不要有台阶

### 2. 组装

```
          侧轴承圆盘（2 块，夹住托架板）
              ↓
    ┌──────[托架]──────┐   ← 镜筒用两条绑带固定在托架上，可以前后滑动调平衡
    │  摇臂箱侧板  侧板 │   ← 侧板的半圆缺口上贴铁氟龙垫片，圆盘边缘压在上面
    │   ┌─前板─┐       │
    └───┴──底板──┴─────┘   ← 底板下面贴防火板
         ◯ M12 转轴
    ════════ 地板 ════════  ← 上面贴三块铁氟龙垫片，下面三个脚
```

1. **托架**：两块托架板竖着放，半圆缺口朝上，间隔约 200 mm（外侧到外侧）。两块侧轴承圆盘从两边夹住托架板，用白乳胶加木螺丝固定。托架板缺口的上沿要和圆盘中心的定位孔**齐平**
2. **侧轴承圆盘边缘**：沿圆周贴一圈 18 mm 宽的防火板条，光面朝外
3. **摇臂箱**：两块侧板立在底板两边，前板装在镜筒口那一侧，**镜筒尾端那一侧不装板**。全部用胶加螺丝固定，用直角尺对正
4. **垫片**：每块侧板的半圆缺口上，在左右各 45° 的位置贴一块铁氟龙垫片（一共 4 块）。地板上表面在三个定位孔处各贴一块（一共 3 块，离中心的距离软件会算好，图纸上已经打了定位孔）
5. **方位转轴**：底板下表面贴防火板，地板下面装三个脚。M12 螺栓从地板下面往上穿过两块板，中间垫尼龙垫片，螺母拧到摇臂箱能顺滑转动、但不松晃为止
6. **刷漆**：刷两遍木器清漆防潮。贴垫片和防火板的地方不要刷
7. **放镜筒**：托架放进摇臂箱，圆盘边缘压在垫片上。镜筒放进托架，让托架中心对准软件算的**重心位置**，用两条绑带扎紧。松手后镜筒停在任何角度都不乱动，就调好了。换上相机或很重的目镜后，松开绑带前后挪一挪

软件会告诉你指向天顶时目镜离地多高（约 120 cm），给孩子准备一个稳当的踏脚凳。

## 第 3 阶段：电动寻星

软件已经写好了 `StepDirDriver` 和 `AltAzMount`（见 `telescope/mount.py`），`build` 命令会算出每个轴每圈多少步，接上下面的电路就能用。

### 接线

| 树莓派引脚 | 接到 |
|---|---|
| GPIO17（物理 11 号针） | 高度轴 TMC2209 的 STEP |
| GPIO27（13 号针） | 高度轴 DIR |
| GPIO22（15 号针） | 方位轴 STEP |
| GPIO23（16 号针） | 方位轴 DIR |
| 3.3 V（1 号针） | 两块驱动板的 VIO，以及 MS1、MS2（两个都接高电平 = 16 细分） |
| GND（6 号针） | 驱动板 GND，和 12 V 电池负极共地 |

- **电源**：两块驱动板的 EN 接 GND（始终使能）。VM 接 12 V，每块驱动板的 VM 和 GND 之间并一个 100 µF 电解电容（注意正负极）
- **电机线**：电机四根线按驱动板标的 A1 A2 B1 B2 接。不知道哪两根是一组，用万用表量，通的两根是一组
- **树莓派供电**：12 V 经过降压模块变成 5 V，接到树莓派的 USB-C 口
- **电池安全**：12 V 电池正极串一个 3 A 保险丝和一个总开关

> ⚠️ **通电状态下绝对不要插拔电机线**，驱动板会立刻烧坏。第一次通电前，先用万用表调驱动板上的电位器，让 Vref 对应电机额定电流的 70% 左右（按驱动板说明书换算）。

### 机械

- **高度轴**：CNC 切好的“高度驱动盘”同心地粘在一块侧轴承圆盘外侧，同步带沿驱动盘边缘绕约半圈，两头固定在盘上。电机用 L 形支架装在摇臂箱侧板外侧，同步带按“Ω”形绕法经过两个惰轮和电机同步轮
- **方位轴**：同步带绕地板边缘一圈，两头固定。电机装在摇臂箱底板上，同样用“Ω”形绕法
- **先测试，再装镜筒**：第一次通电时先**拆下镜筒**，用低速确认方向和步数都对

```python
from telescope.mount import AltAzMount, StepDirDriver
from telescope.sky import observer_for_city

driver = StepDirDriver({"alt": (17, 27), "az": (22, 23)})
mount = AltAzMount(driver, observer_for_city("北京"),
                   alt_steps_per_rev=75398, az_steps_per_rev=120637)  # 用 build 算出的值
```

电机使能时，手推不动底座。以后可以把 EN 接到一个 GPIO 上，在“手推模式”和“电动模式”之间切换，这是下一步要写的软件。

## 第 4 阶段：相机

- 取下 HQ 相机的镜头，装上 C 口转 1.25 寸接筒，像目镜一样插进调焦座
- 焦点已经按相机设计过：调焦座收到底再伸出几毫米就能对上焦（`build` 会给出具体数字）
- 用 `python3 -m telescope optics --aperture 150 --focal 1200 --camera hq` 查看画面能装下多大的天区
- 拍行星时加 2× 巴洛镜

拍摄、叠加降噪、把画面投到平板上，是接下来要写的软件。

## 以后：自己磨一块主镜

真正“从零开始”的做法是自己磨主镜：两块玻璃圆盘对着磨，配上金刚砂，从粗磨、细磨一直到抛光，再用傅科检验仪检测抛物面。150 mm f/8 正好是公认最适合第一次磨的规格。

做完这台望远镜以后，可以买一套“150 磨镜套件”，把磨好的镜子换上去。一般要花 30–60 个小时，适合当一个寒假或暑假的项目。
