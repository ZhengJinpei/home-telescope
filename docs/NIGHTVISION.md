# 动手做一台家用夜视望远镜

白天是 5–9 倍的望远镜，天黑自动变成夜视仪。眼睛贴着目镜看，画面同时推到手机和平板上，全家一起看，还能拍照录像。适合野外看鸟、看动物，看 100–300 m 外的目标。

```
   红外灯（850 nm，不可见光）
   ┌──────┐
   │  ◎   │                        5 个按键
 ┌─┴──────┴─────────────────────┬─┬─┬─┬─┬─┐
 │ 50 mm 镜头 │ 星光级传感器 │ 树莓派 Zero 2 W │ 微型屏幕 │ 目镜 ◉
 └──────────────────────────────┴─────────┘
              两节 18650 电池在下面          Wi-Fi 热点 → 手机
```

**工作原理**：镜头把远处的景物成像在 IMX462 星光级传感器上。这个传感器对近红外光特别灵敏：有月光时不开灯也能出彩色画面；全黑时打开 850 nm 红外灯，就能看到黑白（或绿色）画面。树莓派负责降噪、提亮，再把画面送到目镜里的小屏幕，同时通过 Wi-Fi 推到手机。

## 先在电脑上玩一下

不用任何硬件，先在电脑上跑模拟版，看看按键和画面是什么样：

```bash
pip install numpy pillow
python3 -m nightscope design            # 算放大倍数、看多远、续航
python3 -m nightscope run --simulate    # 浏览器打开 http://localhost:8080
```

模拟版里是一片夜里的树林，一只“鹿”走来走去。默认是有月光的夜晚，3 秒后会自动切到夜间模式。在网页上点“红外 强”“变倍”“拍照”试试。

| 项目 | 数值 |

| 放大倍数 | 4.7×，数码变倍 9.4× / 18.7× |

## 接线

```
18650 ×2（并联）── 充电升压板 ──┬── 5 V ── 树莓派 Zero 2 W（5V、GND 针脚，或 USB 供电口）
                    │           ├── 5 V ── OLED 驱动板
                    │           └── 5 V ── 恒流驱动板 ── 850 nm 红外 LED
                    └── USB-C 充电口
```

| 树莓派针脚（BCM 编号） | 接到 |
|---|---|
| GPIO18（物理 12 号针） | 恒流驱动板的 PWM / 调光脚 |
| GPIO23（16 号针） | 相机模组的 IR-CUT 控制脚（高电平 = 滤镜放进去，白天） |
| GPIO5（29 号针） | 红外按键 |
| GPIO6（31 号针） | 变倍按键 |
| GPIO13（33 号针） | 模式按键 |
| GPIO19（35 号针） | 拍照/录像按键 |
| GPIO26（37 号针） | 关机按键 |
| GND（39 号等） | 所有按键的另一端、恒流驱动板的 GND |

- 按键一端接 GPIO，另一端接 GND，软件里已经打开了内部上拉电阻，不用另外接电阻
- 相机用 CSI 排线接到 Zero 的相机口。Zero 的口比普通树莓派窄，要用 **22 针转 15 针**的排线
- IR-CUT 的控制方式各家不一样：有的模组板上自带驱动，用一根线控制；有的要两根线反向通电。按模组说明接，必要时改 `nightscope/hardware.py` 里的 `DEFAULT_PINS` 和 `set_ircut`
- 恒流驱动板的输出电流按板子说明设到 700 mA 左右（一般是换检流电阻），先用万用表串在 LED 回路里量一下再装进外壳

## 外壳（3D 打印）

主体是一根直径约 60 mm、长约 180 mm 的筒，可以分成三段打印：

| 部分 | 内容 |
|---|---|
| 前段 | 镜头接口（拧上镜头的螺纹段）+ 相机板固定柱；侧面一个小筒装红外 LED 和透镜，和主镜头平行 |
| 中段 | 树莓派 Zero 2 W、恒流驱动板、充电升压板；顶上开 5 个按键孔；底部装电池仓和 1/4 寸三脚架螺母；侧面开 USB-C 充电孔和开关孔 |
| 后段 | OLED 屏幕和目镜，套上橡胶眼罩 |

**注意事项**：
- 打印材料用 **PETG 或 ASA**，PLA 在夏天车里会变形
- 内壁涂哑光黑，防止屏幕的光反射到镜头里
- 红外灯筒和主镜头之间要隔开，否则红外光会从外壳里漏到镜头上，画面发白
- 中段要开几个通风小孔，Zero 2 W 跑满时会发热

外壳的 3D 模型（可以直接发给打印店的 STL 文件）还没做。等零件到手、量好实际尺寸再画。

## 软件安装

1. 用树莓派官方烧录工具（Raspberry Pi Imager）把 **Raspberry Pi OS Lite（64 位，Bookworm）** 写进 TF 卡，烧录时设置好用户名、密码，以及你家的 Wi-Fi（安装软件要用）
2. 开机后，把项目复制到树莓派上，在项目目录里运行：

   ```bash
   sudo bash deploy/setup-pi.sh 你的热点密码
   ```

   这个脚本会做三件事：安装 picamera2 等依赖、建一个叫 **NightScope** 的 Wi-Fi 热点、设置开机自动运行

3. 改两个配置文件（以相机模组和屏幕驱动板的说明为准）：

   `/boot/firmware/config.txt` 末尾加：
   ```
   camera_auto_detect=0
   dtoverlay=imx462
   ```

   `/boot/firmware/cmdline.txt` 这一行的**行末**加一个空格，再加：
   ```
   video=HDMI-A-1:1024x768@60
   ```

4. 重启。手机连 Wi-Fi “NightScope”，浏览器打开 **http://10.42.0.1:8080**

**树莓派开了热点，就连不上你家的 Wi-Fi 了**。以后要更新软件时，先运行 `sudo nmcli connection down NightScope`，再连回家里的 Wi-Fi；更新完重启，热点会自动开回来。

## 按键

| 按键 | 短按 | 长按（1 秒） |
|---|---|---|
| 红外 | 换档：关 → 弱 → 中 → 强（白天不起作用） | 关掉红外灯 |
| 变倍 | 1× → 2× → 4× | 回到 1× |
| 模式 | 白天 / 夜间互换（同时关掉自动切换） | 白天时：恢复自动切换；夜间时：换显示颜色（绿色 / 黑白 / 彩色） |
| 拍照 | 拍一张照片 | 开始 / 停止录像 |
| 关机 | 不起作用（防止误碰） | 关机 |

手机网页上的按钮和实体按键一样，照片和录像也能在网页上下载。

**两种拍摄的区别**：照片是你在目镜里看到的样子，经过降噪和配色；录像是相机的原始画面，夜里是偏粉的彩色，用的是硬件编码，不占 CPU。

## 第一次通电：逐项测试

真机驱动还没在实物上验证过，按顺序一项项测，哪一步不对先停下来查：

1. **只接相机**：运行 `rpicam-hello --list-cameras`，要能看到 imx462
2. **只接屏幕**：运行 `python3 -m nightscope run`，目镜里要有画面。如果看到“不支持 xx 位帧缓冲”，告诉我具体数字
3. **按键**：每个键按一下，看手机网页上的状态有没有变
4. **IR-CUT 滤镜**：切换白天 / 夜间时，能听到滤镜“咔哒”一声。白天画面颜色正常，夜间画面偏粉，说明接对了
5. **红外灯**：用手机**前置**摄像头对着红外灯（很多手机的后置摄像头会滤掉红外），换档时能看到亮度变化。如果夜间画面在“弱”“中”档出现横条纹，是调光的 PWM 频率和相机快门打架，先只用“强”档，告诉我再改频率
6. **自动切换昼夜**：用手捂住镜头 3 秒，应该切到夜间；松手、关掉红外灯后 5 秒，切回白天。如果太灵敏或太迟钝，改 `nightscope/controller.py` 里的 `DARK_BELOW` 和 `BRIGHT_ABOVE`。手机网页的状态里会显示当前的场景亮度（scene_light），可以参考
7. **夜间实测射程**：晚上在空旷的地方，让人站在 50、100、150、200 m 处，记下开强红外灯时能看清到多远。把结果改进 `nightscope/design.py` 的 `IlluminatorRef.range_m`，以后的估算就准了

**流畅度**：在电脑上，夜间处理每帧不到 10 ms；Zero 2 W 慢 10 倍左右，估计能跑到每秒 10–15 帧。如果觉得卡，可以把相机分辨率降到 `--size 768x432`，或者换成树莓派 4。

## ⚠️ 安全

- **不要直视红外灯**。850 nm 红外光人眼几乎看不见，但聚光后的强红外光照久了会伤眼睛。红外灯开着的时候，不要对着人脸，尤其不要对着孩子的眼睛
- **不要买红外激光补光灯**。激光对眼睛的伤害比 LED 大得多，家用一律用 LED
- **18650 锂电池**：买带保护板的；不要用金属物体同时碰正负极；充电时有人看着；外壳不要完全密封，要留出气孔
- **不要拿它看太阳**：白天对着太阳会烧坏传感器，从目镜看也伤眼睛
- 红外灯照向别人家的窗户，属于侵犯隐私，只在野外看动物
