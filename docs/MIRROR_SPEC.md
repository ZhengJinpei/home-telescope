# 主副镜外协技术要求

**用途**：自制 150 mm 牛顿反射天文望远镜（f/8，焦距 1200 mm），目视观测为主。

**数量**：主镜 1 片，副镜 1 片。

数字由 `python3 -m telescope mirror` 算出。换口径或焦距时运行 `python3 -m telescope mirror --aperture 200 --focal 1200 --thickness 33` 重新生成。

## 一、主镜：抛物面反射镜

| 项目 | 要求 |
|---|---|
| 外径 | 150 mm（公差 0 / −0.2 mm） |
| 有效口径 | ≥ 146 mm |
| 中心厚度 | 25 mm（±1 mm） |
| 焦距 | 1200 mm ±1%（曲率半径 R = 2400 mm）。**偏差不要紧，但请告知实测焦距** |
| 面形 | **旋转抛物面，圆锥系数 K = −1**（不是球面） |
| 镜面凹深（矢高） | 1.172 mm |
| 抛物面修正量 | 相对最接近球面约 72 nm（面形） |
| 面形精度 | @632.8 nm：波面 PV ≤ λ/8（合格线 λ/6），波面 RMS ≤ λ/25，斯特列尔比 ≥ 0.9。相当于面形 PV ≤ λ/16 |
| 表面质量 | 疵病 60-40 或更好，粗糙度 Ra ≤ 2 nm |
| 材料 | 首选硼硅玻璃（如 Borofloat 33 类）或微晶玻璃；K9 / BK7 可接受 |
| 背面、侧面 | 细磨。背面平整，与镜面光轴垂直 |
| 倒角 | 镜面一侧和背面一侧边缘都倒 45° × 0.5–1 mm |
| 镀膜 | 增强铝膜，400–700 nm 平均反射率 ≥ 94%，外加二氧化硅保护层。附着力和耐潮湿按厂内标准 |
| 中心标记 | 镜面正中心做一个直径 ≤ 5 mm 的小圆点或圆环（校准光轴用，被副镜挡住，不影响成像）。不方便做可以不做 |

## 二、副镜：椭圆平面镜

| 项目 | 要求 |
|---|---|
| 形状 | 椭圆形平面镜，使用时与光轴成 45° |
| 尺寸 | 短轴 35 mm，长轴 49.5 mm（公差 ±0.2 mm） |
| 厚度 | 6–8 mm |
| 平面度 | 面形 PV ≤ λ/10 @632.8 nm |
| 材料 | 硼硅玻璃、K9 或熔石英 |
| 镀膜 | 与主镜相同 |
| 边缘 | 倒角，背面细磨 |

## 三、检验和交付

请随镜子附上：

1. **主镜干涉检测报告**：干涉图、波面 PV、RMS、斯特列尔比。抛物面用自准直零位检测或补偿检测
2. **主镜实测焦距**（精确到 ±2 mm），我们按实测值设计镜筒长度
3. 副镜平面度检测结果
4. 镀膜反射率曲线（有的话）

**没有干涉仪时**，可以用傅科刀口检验。在球心检验，光源随刀口一起移动，等面积分 4 个带区，各带区刀口相对中心的后退量理论值如下（容许各带区偏差 ≤ 0.1 mm）：

| 带区（半径） | 刀口后退量 |
|---|---|
| 0–37.5 mm | 0.146 mm |
| 37.5–53.0 mm | 0.854 mm |
| 53.0–65.0 mm | 1.450 mm |
| 65.0–75.0 mm | 2.040 mm |

**包装**：镜面贴保护膜或用无尘纸覆盖，单独装盒，四周用泡沫固定，镜面不能接触任何东西。

## 四、如果只能做球面

| 方案 | 结果 |
|---|---|
| 150 mm f/8 做成球面 | 斯特列尔比 0.79，差一点达到衍射极限（0.8），能用但不推荐 |
| 150 mm 球面镜，焦距加长到 1350 mm（f/9） | 斯特列尔比 0.89，球面就够用；镜筒要加长约 15 cm |
| 150 mm 球面镜，焦距 1500 mm（f/10） | 斯特列尔比 0.94，镜筒要加长约 30 cm |

能做抛物面优先做抛物面。f/8 只需修约 72 nm，在抛物面镜里属于最好做的。
