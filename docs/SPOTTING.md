# 动手做一台观鸟镜

一支物镜、一根镜筒，再配上买来的正像棱镜和目镜，就是一台观鸟镜。白天看鸟、看远处的山和船；傍晚和有月光的夜里，用低倍目镜也能看清肉眼看不清的动物。不用电，不用编程。

```
  遮光罩      物镜       镜筒（里面三道遮光环）        调焦座    45° 正像棱镜
 ┌───────┐┌─────────┐┌──────────────────────────┐┌─────┐  ╱‾‾‾‾╲
 │       ││ ◖ ED ◗  ││  │      │      │          ││     │─╱      ╲── 目镜 ◉
 └───────┘└─────────┘└──────────────────────────┘└─────┘
   120 mm    外协          285 mm 铝管                 买          买     买
                            ▲ 三脚架抱箍
```

所有尺寸都由软件算出来：

```bash
python3 -m telescope spotting --out 打印件
```

## 规格

| 项目 | 数值 |
|---|---|
| 物镜 | 80 mm 口径，焦距 480 mm（F/6），ED 低色散双分离 |
| 倍率 | 12×（傍晚）、15×（找目标）、20–60×（变焦看细节） |
| 视场 | 低倍 3.2°，100 m 外能看到 5.6 m 宽 |
| 最近对焦 | 约 5.6 m |
| 镜筒 | 6061 铝管 Φ90 × 2 mm，长 285 mm |
| 总重 | 约 1.8 kg（含棱镜和目镜） |

### 傍晚和月光下能看到什么

纯光学望远镜**不会让景物比肉眼看到的更亮**，最多和肉眼一样亮（再扣掉镜片的一点损耗）。它的作用是**放大**：傍晚肉眼只能看到远处一团影子，放大 12 倍后就能认出是一只鹿还是一条狗。

要做到“和肉眼一样亮”，出瞳（目镜后面那个小光斑）要和眼睛的瞳孔一样大。傍晚成年人的瞳孔约 6 mm，孩子约 7 mm：

| 目镜 | 倍率 | 出瞳 | 傍晚亮度（成人 / 孩子） | 适合 |
|---|---|---|---|---|
| 40 mm 普洛 | 12× | 6.7 mm | 85% / 77% | **傍晚、月光下** |
| 32 mm 普洛 | 15× | 5.3 mm | 67% / 49% | 白天找目标，傍晚也还行 |
| 8–24 mm 变焦 | 20–60× | 4.0–1.3 mm | 38% → 4% | 白天看细节 |

**全黑的夜里看不见**。全黑时要看东西，需要电子夜视仪（见 [NIGHTVISION.md](NIGHTVISION.md)）。

## 物镜外协要求

运行 `python3 -m telescope spotting` 会打印这一份要求，可以直接发给光学厂：

| 项目 | 要求 |
|---|---|
| 类型 | ED 双分离：一片 ED 低色散玻璃（如成都光明 H-FK61，相当于 FPL-51）配一片镧系或重冕玻璃，空气间隔或胶合均可 |
| 通光口径 | 80 mm，不小于 78 mm |
| 焦距 | 480 mm ±1%（F/6），请告知实测值 |
| 像质 | @546 nm 波面 PV ≤ λ/4，斯特列尔比 ≥ 0.8；486–656 nm 色差校正 |
| 镀膜 | 每个面宽带多层增透膜，450–650 nm 平均反射率 ≤ 0.5% |
| 边缘 | 镜片侧面涂黑 |
| 交货 | **装进镜座、调好间隔和偏心后交货**（偏心 ≤ 0.02 mm）；镜座后端加工成和 Φ90 × 2 铝管配合的止口 |

**一定要请厂家把镜片装进镜座再交货**。双分离物镜两片镜片之间的间隔和对中，误差几十微米就会让成像变糊，自己装很难装准，厂家有专用的定心设备。

**为什么选 ED 玻璃**：普通消色差物镜在 F/6 时色差明显（色差指数 1.9，低于 3 就会看到），看白色的鸟、逆光的树枝，边缘会有紫边，倍率越高越明显。ED 玻璃基本消除了这个问题。厂家只能做普通消色差也可以用：低倍（12–20 倍）看着差别不大，倍率越高紫边越明显。要把色差压到看不出来（色差指数 3 以上），焦距得加长到 760 mm 左右，镜筒要长近 30 cm，不划算，不如把变焦目镜用在 30 倍以内。

**正像棱镜为什么要 2 寸的**：1.25 寸的棱镜便宜一半，但通光孔径只有 25 mm 左右，用 40 mm 和 32 mm 目镜时视场边缘会暗一半，正好影响傍晚观察。想先省钱可以用 1.25 寸的，运行 `--prism 1.25` 看一下效果。

**不需要工具**。铝管让卖家按长度切好、两端车平；其余全是拧螺丝和插接。

## 3D 打印件

`python3 -m telescope spotting --out 打印件` 会生成 6 个 STL 文件，可以直接发给打印店：

| 文件 | 零件 | 说明 |
|---|---|---|
| `dew_shield.stl` | 遮光罩 | 长 120 mm，套在物镜镜座外面，挡侧面来的光，也防止镜片结露 |
| `lens_cap.stl` | 镜头盖 | 盖在遮光罩前端 |
| `liner_1.stl`–`liner_3.stl` | 内衬筒（带遮光环） | 每节 71 mm 长，后端有一圈遮光环，孔径依次是 73、65、57 mm |
| `liner_4.stl` | 内衬筒 | 没有遮光环，最后塞进去，把前面三节顶住 |

- 材料用**黑色 PETG**，哑光最好，能减少镜筒内的反光
- 填充 20% 就够；内衬筒壁很薄（1.2 mm），让打印店用 0.4 mm 喷嘴、2 圈外壁
- 遮光环的作用：只让成像需要的光通过，把镜筒内壁反射的杂光挡掉。没有它，看逆光景物时画面会发灰

**换了物镜或镜筒以后**，运行 `spotting` 时加上 `--aperture`、`--focal`、`--tube-od` 等参数重新生成。软件会自动重新计算遮光环的位置和孔径。

## 组装

1. **检查镜筒**：铝管内壁如果是亮的，喷一层哑光黑漆，晾干
2. **装内衬筒**：从镜筒**前端**依次塞进内衬筒 1、2、3（遮光环朝后），再从**后端**塞进内衬筒 4。四节加起来正好是镜筒长度，装上物镜和调焦座后就被夹紧了
3. **装物镜**：把物镜镜座的止口插进镜筒前端，拧紧固定螺丝。**不要碰镜片表面**
4. **装调焦座**：按调焦座的接口装到镜筒后端
5. **装正像棱镜和目镜**：棱镜插进调焦座，拧紧；目镜插进棱镜
6. **套上遮光罩**，装上抱箍：抱箍中心离镜筒前端约 216 mm，装好目镜后松开抱箍前后挪一挪，手松开时镜筒不往前也不往后栽，就平衡了

## 第一次使用

1. **白天先对焦**：找 1 km 外的楼顶或电线塔，用 32 mm 目镜慢慢转调焦旋钮，直到清楚
2. **校准光轴不用你做**：物镜是厂家装好调好的，没有需要校准的地方
3. **看近处**：调焦座往外拉，最近能看清 5–6 m 外，可以看院子里的鸟食台
4. **傍晚**：换上 40 mm 目镜。太阳落山后半小时内，是看动物最好的时候

## ⚠️ 安全

- **永远不要用它看太阳**，包括日出日落时。一瞬间就会造成永久失明。不用时盖好镜头盖
- 不要把望远镜放在阳光直射的地方。物镜会把阳光聚成一个点，可能点燃东西
- 孩子用的时候，大人先确认方向，再让孩子看
