# 家用夜视望远镜 & 家庭天文望远镜

和孩子一起看远处、看夜里、看星星的小项目，分两部分：

- **🌙 家用夜视望远镜（`nightscope`）**：白天是 5–9 倍望远镜，天黑自动变成夜视仪。星光级传感器 + 红外补光，目镜里看，同时推到手机。**制作指南：[docs/NIGHTVISION.md](docs/NIGHTVISION.md)**
- **🔭 家庭天文望远镜（`telescope`）**：今晚看什么、天象日历、光学计算、自制牛顿反射镜的尺寸和切割图纸、模拟自动寻星

## 🌙 家用夜视望远镜

```bash
pip install numpy pillow
python3 -m nightscope design            # 放大倍数、视场、红外灯能照多远、续航
python3 -m nightscope run --simulate    # 不用硬件，浏览器打开 http://localhost:8080 试玩
```

| 功能 | 说明 |
|---|---|
| 自动昼夜 | 天黑 3 秒自动切到夜间：红外截止滤镜移开，可以开红外灯；天亮自动切回 |
| 夜间画质 | 多帧降噪（按 8×8 小块判断运动，不拖影）、自动对比度、绿色 / 黑白 / 彩色三种显示 |
| 变倍 | 1× / 2× / 4×，由相机的图像处理器裁剪，不占 CPU；倍率越高曝光越短，手持不糊 |
| 手机同步 | 树莓派开 Wi-Fi 热点，手机浏览器看实时画面、按按钮、下载照片录像；页面全暗红色，不晃眼 |
| 拍照录像 | 照片是目镜里看到的样子，录像用硬件 H.264 编码 |
| 硬件 | 树莓派 Zero 2 W + IMX462 + 50 mm F1.4 镜头 + 0.39 寸 OLED 目镜 + 850 nm 红外灯 + 两节 18650，约 1000–1600 元 |

真机驱动（picamera2、gpiozero、帧缓冲）已经写好，但还没在实物上验证。零件到手后按 [docs/NIGHTVISION.md](docs/NIGHTVISION.md) 的“第一次通电”逐项测试。

# 🔭 家庭天文望远镜

## 现在能做什么（v0.3）

| 功能 | 命令 | 说明 |
|---|---|---|
| 🌙 今晚看什么 | `tonight` | 按你的城市和望远镜，列出今晚值得看的目标，标出最佳时间、方向、高度和难度 |
| 🔭 光学计算器 | `optics` | 倍率、视场、出瞳、分辨率、极限星等，提示倍率是否过高，推荐目镜和相机搭配 |
| 📍 它在哪 | `where` | 任意目标此刻的方位和高度（"东南方，高 37°"），附一段讲给孩子听的话 |
| 📅 天象日历 | `events` | 月相、行星合月、月掩星、行星相合、冲日、水星金星大距、七大流星雨、日食和月食，只列出你所在城市看得到的，告诉你几点、往哪看 |
| 🛠 自己做望远镜 | `build` | 按你的主镜算出镜筒长度、调焦座位置、副镜大小、重心、多布森底座尺寸和电机步数，生成给 CNC 切割店的图纸 |
| 🪞 镜片外协参数 | `mirror` | 主镜和副镜交给光学厂加工时要写清楚的尺寸、抛物面、精度、镀膜和检验数据；只能做球面时焦距要多长 |
| 🤖 自动寻星 | `goto` | 模拟电动支架转向目标，算出两个电机各转多少步 |
| ☀️ 太阳保护 | 内置 | 拒绝对准太阳、拒绝靠近太阳的目标、拒绝转动路径扫过太阳，白天提醒盖好镜头盖 |
| 📖 儿童讲解 | 内置 | 40 多个目标，每个都有一段中文小故事 |

目标包括：月亮和七大行星、17 颗亮星、2 对漂亮的双星、15 个梅西耶天体和双星团。

## 快速开始

```bash
git clone <本仓库地址>
cd home-telescope

# 今晚北京能看什么（用 70 mm 口径、700 mm 焦距的入门望远镜）
python3 -m telescope tonight --city 北京 --aperture 70 --focal 700

# 土星现在在哪
python3 -m telescope where 土星

# 我的望远镜配 25 mm 和 10 mm 目镜分别是多少倍
python3 -m telescope optics --aperture 70 --focal 700 --eyepiece 25 10

# 接下来 60 天有什么天象（月食、流星雨、行星合月……）
python3 -m telescope events --city 北京 --days 60

# 自己做一台 150 mm 反射望远镜：算尺寸、生成木板切割图纸
python3 -m telescope build --out 图纸

# 模拟自动寻星：先用织女星校准，再转向辇道增七
python3 -m telescope goto 辇道增七 --align 织女星

# 全部目标
python3 -m telescope list
```

不在列表里的城市用 `--lat 纬度 --lon 经度`；指定时间用 `--time "2026-10-10 21:00"`。
`tonight` 最后会附上近 7 天值得关注的天象；`events --all` 会把本地看不到的也列出来。

示例输出：

```
2026-10-10 晚上（北纬 39.9°，东经 116.4°）
  天黑：18:20  完全黑：18:50 – 05:20  天亮：05:50
  月相：新月（亮面 0%）

 1. 木星（行星，-1.7 等）难度 ★    最佳 05:50，东南方高 47°
 2. 土星（行星，+0.5 等）难度 ★    最佳 23:40，南方高 52°
 ...
```

## 精度

行星和月亮用 Paul Schlyter 的简化轨道算法，2025–2029 年间与 astropy 对比：

| 天体 | 最大误差 |
|---|---|
| 太阳、行星 | 1–3 角分 |
| 月亮 | 约 6 角分 |
| 恒星（已做岁差改正） | < 1 角分 |

低倍目镜的视场通常在 1° 以上（60 角分），完全够用。

天象日历与 NASA 月食表、astropy 对比（北京）：

| 天象 | 误差 |
|---|---|
| 月相时刻 | 约 3 分钟 |
| 月食各阶段（2026-03-03 月全食） | 约 3 分钟，食分差 0.01 |
| 日食开始、最大、结束（2030、2032、2035） | 约 3 分钟，食分差 0.01–0.02 |
| 月掩星（2026 年两次月掩轩辕十四） | 约 3–5 分钟 |
| 冲日、大距、流星雨极大 | 日期准确 |

全食带、环食带边缘附近说不准是全食还是偏食，软件会提示以天文台预报为准。

## 🔭 动手做一台真正的望远镜

**[制作指南 docs/BUILD.md](docs/BUILD.md)**：150 mm f/8 牛顿反射镜加多布森底座。主镜和副镜外协加工（参数见 [docs/MIRROR_SPEC.md](docs/MIRROR_SPEC.md)），镜筒、主镜座、底座、电机和电路都自己做。木板交给 CNC 切割店加工，不需要木工工具。指南里有购物清单、工具清单、分步骤说明，还标了哪些步骤适合孩子做。

## 一步步升级的路线

### 第 1 步：手动望远镜 + 本软件（现在就能玩）
- 买一台 70–80 mm 入门折射镜，或者按 [docs/BUILD.md](docs/BUILD.md) 自己做一台 150 mm 反射镜
- 70 mm 口径就能看土星光环、木星卫星和月面环形山
- 用 `tonight` 选目标，用 `where` 知道往哪个方向找

### 第 2 步：加相机，拍下来给孩子看
- 树莓派 4/5 + 树莓派 HQ 相机（或 USB 行星相机）
- `optics --camera hq` 会告诉你这台望远镜接相机后视野多大、能不能拍下整个月亮
- 待开发：拍摄、叠加降噪、实时画面投到平板

### 第 3 步：电动支架，自动寻星
- 两个 NEMA17 步进电机 + TMC2209 驱动板 + 同步带减速
- 代码里已有 `StepDirDriver`，按下面的方式接线后换掉 `SimulatedDriver` 即可；自己做的多布森底座的接线和每圈步数见 [docs/BUILD.md](docs/BUILD.md) 第 3 阶段
- ⚠ 真机驱动还没在硬件上验证，第一次通电请先拆下镜筒、低速测试

```python
from telescope.mount import AltAzMount, StepDirDriver
from telescope.sky import observer_for_city

driver = StepDirDriver({"alt": (17, 27), "az": (22, 23)})  # (STEP 引脚, DIR 引脚)
mount = AltAzMount(driver, observer_for_city("北京"))
```

### 以后可以加的功能
- 🎤 语音："带我去看土星"，接 Claude 讲解看到的画面
- 🧭 星图解算（plate solving）：拍一张照片就知道望远镜指向哪里，免校准
- 📓 观测日志：记录孩子每次看到了什么，攒成"星空护照"
- 📱 手机网页遥控

## ⚠️ 安全第一

- **永远不要用望远镜或寻星镜看太阳**，一瞬间就会造成永久失明。软件会拒绝对准太阳，但不能代替大人看护
- 白天使用时盖好主镜和寻星镜的盖子
- 想看太阳必须用正规的**镜前**太阳滤膜（不是目镜端的那种）
