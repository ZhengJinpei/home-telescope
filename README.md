# 家庭智能望远镜

和孩子一起看星星的小项目：先用软件告诉你**今晚看什么、它在哪、用什么目镜**，再一步步加上相机和电动支架，最后做成会自己找星星的望远镜。

所有代码都是纯 Python 标准库，**没有望远镜也能先在电脑上玩**。

## 现在能做什么（v0.1）

| 功能 | 命令 | 说明 |
|---|---|---|
| 🌙 今晚看什么 | `tonight` | 按你的城市和望远镜，列出今晚值得看的目标，标出最佳时间、方向、高度和难度 |
| 🔭 光学计算器 | `optics` | 倍率、视场、出瞳、分辨率、极限星等，提示倍率是否过高，推荐目镜和相机搭配 |
| 📍 它在哪 | `where` | 任意目标此刻的方位和高度（"东南方，高 37°"），附一段讲给孩子听的话 |
| 🤖 自动寻星 | `goto` | 模拟电动支架转向目标，算出两个电机各转多少步 |
| ☀️ 太阳保护 | 内置 | 拒绝对准太阳、拒绝靠近太阳的目标、拒绝转动路径扫过太阳，白天提醒盖好镜头盖 |
| 📖 儿童讲解 | 内置 | 40 多个目标，每个都有一段中文小故事 |

目标包括：月亮和七大行星、17 颗亮星、2 对漂亮的双星、15 个梅西耶天体和双星团。

## 快速开始

```bash
git clone <本仓库地址>
cd home-telescope

# 今晚北京能看什么（用 70 mm 口径、700 mm 焦距的入门望远镜）
python3 -m telescope tonight --city 北京 --aperture 70 --focal 700

# 土星现在在哪
python3 -m telescope where 土星

# 我的望远镜配 25 mm 和 10 mm 目镜分别是多少倍
python3 -m telescope optics --aperture 70 --focal 700 --eyepiece 25 10

# 模拟自动寻星：先用织女星校准，再转向辇道增七
python3 -m telescope goto 辇道增七 --align 织女星

# 全部目标
python3 -m telescope list
```

不在列表里的城市用 `--lat 纬度 --lon 经度`；指定时间用 `--time "2026-10-10 21:00"`。

示例输出：

```

  天黑：18:20  完全黑：18:50 – 05:20  天亮：05:50
```

## 精度

行星和月亮用 Paul Schlyter 的简化轨道算法，2025–2029 年间与 astropy 对比：

| 天体 | 最大误差 |
|---|---|
| 太阳、行星 | 1–3 角分 |
| 月亮 | 约 6 角分 |
| 恒星（已做岁差改正） | < 1 角分 |

低倍目镜的视场通常在 1° 以上（60 角分），完全够用。

## 一步步升级的路线

### 第 1 步：手动望远镜 + 本软件（现在就能玩）
- 入门折射镜，70–80 mm 口径就能看土星光环、木星卫星和月面环形山
- 用 `tonight` 选目标，用 `where` 知道往哪个方向找

### 第 2 步：加相机，拍下来给孩子看
- 树莓派 4/5 + 树莓派 HQ 相机（或 USB 行星相机）
- `optics --camera hq` 会告诉你这台望远镜接相机后视野多大、能不能拍下整个月亮
- 待开发：拍摄、叠加降噪、实时画面投到平板

### 第 3 步：电动支架，自动寻星
- 两个 NEMA17 步进电机 + TMC2209 驱动板 + 同步带减速
- 代码里已有 `StepDirDriver`，按下面的方式接线后换掉 `SimulatedDriver` 即可
- ⚠ 真机驱动还没在硬件上验证，第一次通电请先拆下镜筒、低速测试

```python
from telescope.mount import AltAzMount, StepDirDriver
from telescope.sky import observer_for_city

driver = StepDirDriver({"alt": (17, 27), "az": (22, 23)})  # (STEP 引脚, DIR 引脚)
mount = AltAzMount(driver, observer_for_city("北京"))
```

### 以后可以加的功能
- 🎤 语音："带我去看土星"，接 Claude 讲解看到的画面
- 🧭 星图解算（plate solving）：拍一张照片就知道望远镜指向哪里，免校准
- 📅 天象日历：流星雨、月食、行星合月提醒
- 📓 观测日志：记录孩子每次看到了什么，攒成"星空护照"
- 📱 手机网页遥控

## ⚠️ 安全第一

- **永远不要用望远镜或寻星镜看太阳**，一瞬间就会造成永久失明。软件会拒绝对准太阳，但不能代替大人看护
- 白天使用时盖好主镜和寻星镜的盖子
- 想看太阳必须用正规的**镜前**太阳滤膜（不是目镜端的那种）
